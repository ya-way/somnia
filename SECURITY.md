# Security policy

Somnia v0.1 is a pre-release static prototype. It has no authentication or backend and is not suitable for processing sensitive health data in production.

Do not place model API keys in the frontend. Do not post sensitive data or exploit details involving another person's information in public issues.

For a non-sensitive bug, open an issue with synthetic reproduction data. For a sensitive vulnerability, use GitHub's private vulnerability reporting option if available. If it is not enabled, request a private contact route without publishing the vulnerability or affected data.

Only the latest source on `main` is maintained. There is no guaranteed security response time for this experimental release.
